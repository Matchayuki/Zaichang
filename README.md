# 在场 · 陪你把关心说出口

一个面向“收到朋友倾诉，却不知道怎么回”的独立 Web 应用。EchoGlow 帮人表达感受，在场帮接收者试着回应；也可以只拿一段普通聊天来用。两者没有账号、数据或运行依赖。

## 使用

直接打开 `index.html` 可以浏览界面，但 AI 生成需要通过 `server.cjs`，不能用静态文件服务器代替。初始内容是明确标注的虚构练习，可以换成朋友的原话。

1. **听见TA**：看一段原话，或试一个虚构场景；只选择朋友明确说过的请求。
2. **看看自己**：选择此刻能陪多少。没有选择时不会进入回应步骤。
3. **回一句话**：把草稿修改成自己的语气，再复制到聊天里。可以返回调整，手改文字不会被自动覆盖。

想继续陪伴时，从回应后的入口或顶部「留一点时间」，再约一件具体的小事。自己记录“TA说好啦”之后，可导出个人日历。

本地开发：`node test.cjs`、`node build.cjs`。`dist/` 包含六个静态资源，可独立移动。静态服务器预览示例：`python -m http.server 4182 --bind 127.0.0.1`。

## 产品边界

- 不是心理咨询、测谎或情绪识别。回应由 DeepSeek 根据原话、可选背景、朋友明确表达的需要和用户自己的余力生成；用户可编辑、核对后再复制。
- 没有代发、聊天回执、好友关系、多人同步或自动提醒。状态来自用户自己的记录，不是对方的授权凭据。
- 默认不保存。主动保存时只保留一份本机约定；不保存聊天原话或回复。键为 `zaichang_plan_v1`，不访问 EchoGlow 的存储。
- 手改草稿不会因选择变化被替换；需要本人确认重新整理。修改时间或安排会撤销之前的确认和完成状态。
- 日历采用 UTC 时间和转义后的文本，不携带昵称、不发邀请、不添加自动提醒。日历服务仍可能同步用户填写的安排细节；`CLASS:PRIVATE` 不是加密。
- 不使用外部字体、分析埋点或前端 API Key。AI 服务端通过环境变量接入 DeepSeek，插画是项目内置资源。
- 纯静态页面可部署到 GitHub Pages，但只能使用原有浏览和本地约定功能；要启用 AI，需要把 `server.cjs` 部署到支持 Node.js 的服务，并设置密钥。

## 实现与验证
